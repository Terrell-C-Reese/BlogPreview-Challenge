How did using Figma designs as references affect your coding process?


The figma designs helped me think of this project in small blocks of code rather than a giant chunk.
Using this resource also made it easier to set up containers for each part of the projects when it came to the HTML.
It also helped with naming conventions for both the HTML and CSS aspects.<br>



What challenges did you encounter when aligning your code with the design specifications?


Outside of still adapting to grid-box and flex-box things, I think the primary challenge for me was 
getting the colors to match closely. Every screen and/or monitor displays colors slightly differently 
so I was trying to guess the exact colors by connecting multiple monitors to my laptop and trying to 
find the median between the three. While I was doing this, someone suggested using an online color picker
to get the exact hex for each color. That was MUCH quicker.<br>



How can the feedback and community resources on Frontend Mentor help you improve as a developer?


I really enjoyed doing these challenges because it forced me to break down each aspect of the project into
more maintainable blocks of code. It was like building a car with Lego bricks. It allowed me to make better 
decisions on using specific tags, containers and screen sizing things via media queries. There is more than 
one way to solve these challenges but I found my way of going about doing so. <br>
